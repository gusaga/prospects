Local enricher

Don’t open this link directly

/requests/enrich/run only works when the green Run enricher button sends a form (POST) with selected prospects. Pasting the URL in the address bar cannot start a search.

Do this instead

  1. Go to Prospects.
  2. Check one or more people.
  3. Click the green Run enricher button (not “Open brief”).
  4. Wait 30–90 seconds — keep the tab open until you see Enricher results.

If you still get “Not Found”, the CRM app needs a restart so it loads the new enricher route: stop the terminal running the app, then start it again with python -m crm.
