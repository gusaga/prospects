Prospecting CRM

From the GitHub link to your first call list

You got a link to the repo. Here is exactly what you need, what to click, and where your data is saved — on your computer only.

What you need first

1. A Windows PC

This guide is for Windows. Mac/Linux work too with the Python commands in the README.

2. Python 3.11+

Install from python.org. Check Add python.exe to PATH.

3. The project folder

Download the ZIP from GitHub, or clone with Git. Unzip somewhere easy to find.

First-time journey

  1. Open the GitHub repo

    Go to https://github.com/gusaga/prospects. Click the green Code button → Download ZIP (or clone if you use Git).

  2. Unzip the folder

    Extract it (e.g. to Documents\prospects). You should see files like setup.bat, README.md, and a crm folder.

  3. Run setup once

    Double-click setup.bat. It checks Python, creates .venv, and installs the app. When asked, you can start the CRM immediately.

    setup.bat

  4. Open the app

    If setup didn’t start it: double-click run.bat. Your browser should open http://127.0.0.1:8765.

    run.bat

  5. Tell it who you sell to (ICP)

    Go to Settings. Fill product, industry, regions, titles, and account rule — or click Load example ICP and edit it. Without this, research briefs don’t know who to find.

  6. Start researching

    Open Research, create a request, copy the brief into your AI research agent — or add prospects by hand. Use Today when you’re ready to dial.

Where things are saved

This GitHub folder

Application only

…\prospects\ ├── setup.bat ├── run-live.bat ├── crm\ └── schemas\

Code and instructions. No calling list lives here.

Your lists

Data in Documents

Documents\ProspectingCRM\ ├── data\crm.db ├── inbox\ └── backups\ …\prospects\run-live.bat

Keeps your calling list safe when you update code from GitHub.

Move to a safe data home

After setup, double-click run-live.bat once. It opens a picker for folders under Documents\ProspectingCRM* (never overwrites an existing database) and starts the one you choose.

Second business = second folder

Don’t mix lists. On the picker, use Start a new list (e.g. name it Dental → Documents\ProspectingCRM-Dental). Each folder is a separate calling list.
